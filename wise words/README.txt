WISE WORDS BY TRUMP - LANDING PAGE REDESIGN
================================================

Files:
- index.html
- style.css
- script.js

How to view:
1. Keep all 3 files in the same folder.
2. Double-click index.html.
3. Open it in Chrome.

Included:
- Premium responsive landing page from header to footer
- White/black theme toggle
- Social icons in header/footer
- Home, About, Pre-sale, Blog and Contact navigation
- Product/edition cards with hover effects
- Pre-order modal with Information -> Payment -> Confirmation steps
- Quantity controls and reference-code field
- Responsive mobile navigation
- Sample blog section for design only
- Contact section with placeholder contact details
- CSS-only notebook visuals so the demo works as a local file

Important:
- Payment is front-end demo only. No real payment is processed.
- Replace placeholder contact/social URLs, author text, blog copy, edition names/prices,
  and payment gateway details with the client's approved information before launch.
- Google Fonts are loaded from the web. The page still works locally if the font request
  is unavailable, using the fallback fonts.
